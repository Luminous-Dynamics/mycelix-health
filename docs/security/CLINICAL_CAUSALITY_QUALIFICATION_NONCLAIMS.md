# Clinical Causality Qualification v1 — non-claims

This stack must not be described as proving any of the following until separate evidence exists:

- that a clinical observation is physically true rather than correctly recorded;
- that a causal assessment establishes population-level treatment effect;
- that temporal association alone supports causation;
- that an imported historical causality label is independently validated;
- that a licensed assessor may use arbitrary evidence sources;
- that a trusted evidence source may substitute for professional assessor authority;
- that a pure Rust qualification receipt proves DHT provenance;
- that a DHT attestation proves the underlying physical clinical event occurred;
- that regulatory reportability is universal across jurisdictions/protocols;
- that current source review is equivalent to CI, conductor, clinical, regulatory, or deployment qualification.
